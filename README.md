# aws-ec2-linux-server-project
My first hands-on AWS project deploying and managing a Linux server using EC2.
AWS EC2 Linux Server Project

Project Overview

This project involved deploying and accessing a Linux virtual server using Amazon Web Services (AWS) EC2. The goal was to gain hands-on experience with cloud infrastructure and basic Linux server administration.

Technologies Used

Amazon Web Services (AWS)

Amazon EC2

Amazon Linux 2023

Linux command line

Server Configuration

Instance type: t3.micro

Operating system: Amazon Linux 2023

Storage: 8 GiB

AWS Region: US East (N. Virginia)

Tasks Completed

Created and configured an EC2 instance.

Connected to the Linux server using EC2 Instance Connect.

Created and navigated directories.

Created, edited, copied, and renamed files.

Inspected file permissions.

Checked disk space and memory usage.

Identified the operating system and hostname.

Inspected running processes.
